Modified the pap lite to intergrate a little more into the dragon burner toolhead.  I wanted to drop the extruder lower to decrease the filament path from the extruder to the hotend as well as add a little aesthetics.  The front cover also helps prevent the top screw(s) from backing out or coming loose.
